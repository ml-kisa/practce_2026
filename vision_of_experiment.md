Видение эксперимента 
Работа посвящена исследованию влияния качества данных на validation loss малых GPT-подобных моделей. Ключевой вопрос исследования: как различные типы деградации обучающих данных влияют на качество языковых моделей и изменяется ли устойчивость при увеличении числа параметров.
Предполагается, что искусственная деградация обучающих данных увеличивает validation loss относительно clean baseline.
Гипотезы: 
1.	Noken noise сильнее ухудшает функцию потерь, чем shuffling и duplicates
2.	Увеличение уровня деградации с 25% до 75% приводит к монотонному росту функции потерь
3.	Крупные модели демонстрируют меньший относительный рост loss при умеренной деградации данных
В качестве baseline используется GPT-подобная модель на базе nanoGPT, обученная на корпусе FineWeb-Edu
Размеры рассматриваемых моделей: 1М, 4М, 16М 
Для каждого из размеров рассматриваемых моделей предлагаются следующие типы деградаций: Clean, Duplicates, Shuffling, Token noise
Уровни интенсивности этих деградаций: 0% (clean), 25%, 50%, 75%
В качестве исходного корпуса используется FineWeb-Edu – открытый англоязычный датасет (https://huggingface.co/datasets/HuggingFaceFW/fineweb-edu). Он содержит 1В токенов, после токенизации GPT-2 BPE: 900М токенов для обучения и 100М токенов для валидации. Все искусственные деградации применяются только к обучающей части – проверочная часть остается неизменной для для всех экспериментальных условий. 
Ключевой метрикой для отслеживания результата обучения всех моделей в эксперименте является значение функции потерь на валидационном наборе данных – validation loss.
Основными факторами искажения результатов выступают сделующие ситуации: 
1.	Недостаточное количество обработанных токенов и недообучение модели
2.	Случайная инициализация весов модели
3.	Смешение данных между обучающим и валидационным корпусами
4.	Случайные колебания значения функции потерь при оценке по небольшим выборкам данных.
Для снижения вероятности возникновения вышеперечисленных факторов в эксперименте планируется использовать фиксированные конфигурации, одинаковый набор валидационных данных, контролируемое количество обучающих токенов, а также повторные запуски для наиболее значимых условий.
Основная вычислительная среда для проведения эксперимента – Google Colab, GPU T4. Google Drive используется для хранения корпуса, конфигураций моделей и логов. Исходный корпус сохраняется в полном объеме, при этом отдельно учитывается фактическое количество токенов, обработанных каждой моделью во время обучения. 
Результатом работы планируется экспериментальная таблица значений функции потерь для всех моделей, на основе которой будут построены графики зависимости рассмотренной validation loss от числа параметров модели, изменения loss при различных уровнях деградации и относительной устойчивости моделей.
Эксперимент позволит установить, какие типы деградации оказывают наиболее значимое влияние на качество малых GPT-подобных моделей и проверить, сохраняется ли преимущество увеличения размера модели при ухудшении обучающих данных.
